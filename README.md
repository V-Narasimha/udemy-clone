🎓 Udemy Clone Website

A responsive front-end clone of the Udemy homepage built using HTML5 and CSS3.
This project recreates the layout, design, and structure of the Udemy platform for learning and practice purposes.

🚀 Project Overview

This project focuses on building a real-world website layout using modern CSS techniques like Flexbox and responsive design principles.

The website includes:

Navigation bar with logo, search bar, and menu links

Category navigation section

Hero banner section

Recommended courses section

Course cards with images and details

Clean and modern UI design

🛠️ Technologies Used

HTML5

CSS3

Flexbox


✨ Features

🔍 Functional UI search bar (design only)

🎨 Modern category buttons

📱 Responsive layout

🖼️ Hero banner with promotional design

📚 Course recommendation section

🧩 Structured and reusable layout components
